# 序列字符串切分 v1

面向教学序列编辑。输入molecule包含ASCII id、topology=linear/circular、1..200000个大写ACGT字符；enzymes为1..50条用户给定的id、motif(1..32且不长于序列)和cut_after(0..motif长度)。不查酶数据库，不声称示例是实验酶；拒绝IUPAC模糊字母、甲基化、突变或实验条件。匹配工作量len(sequence)×Σlen(motif)≤10^7。

把输入当作一条标记方向的字符串。识别原motif及其反向互补串，所有起点包括重叠命中都保留。正向切口=start+cut_after；反向切口=start+motif_length-cut_after。回文motif只保留正向一次，不额外推导另一条链切口。这是明确的字符串切分约定，不是双链限制酶、黏性末端或突出端化学模型；不输出可用于实验操作的条件或方案。

坐标0起，切口在字符间；线性坐标范围[0,n]，首尾命中是有效识别但不产生零长片段。环状搜索只遍历0..n-1的起点，允许识别跨源点，切口模n。所有酶同一轮对原始完整序列识别，不顺序重扫已切片段。命中保留enzyme/start/orientation/wraps_origin证据，实际切口合并去重。

线性以0和n及全部切口升序分段；环状有切口时从最小切口开始，逐切口走到下一切口，最后跨源点；一个切口会将全环展开为一条长度n的线性片段，无切口时保留起点0的环片段。每片提供正向sequence、source_spans半开区间、length、ASCII序列SHA256及由原分子id/顺序编号组成的fragment_id；不把哈希当作方向无关身份。片段长度总和必须等于原序列长度，拒绝静默丢失字符。

成功先完成全部识别/切分再原子新建JSON，不覆盖已有目标或链接。结构错误退出2；没有命中属于正常结果。没有FASTA/GenBank解析、实验调用、联网或医疗解释。
